# Forever Anvil addon

The site's prices inside the game. Version 1 is a read-only helper (see [docs/addon-plan.md](../docs/addon-plan.md)):

- **Tooltips:** market and lowest price on your auction house, sold per day, region median, disenchant value, vendor price, data age.
- **Auction house (Browse):** tags listings worth buying to sell to a vendor (`Vendor +X`) or to disenchant (`DE +X`).
- **Profession window:** profit per craft next to each recipe.
- **Settings:** Esc → Options → AddOns → Forever Anvil, or `/fa options`. `/fa` shows which house you're on.

## Folders

| Folder | What it is |
|---|---|
| `ForeverAnvil/` | The addon itself (Lua). `Math.lua` has no game calls and is tested against the site's JS in `pipeline/addon.test.js`. |
| `ForeverAnvil_Data_EU/`, `_US/` | Price data, generated by `npm run addon` (from `./out`, or the live site with `--live`). Not committed. |

## Try it in game

1. Build the data from the live site: `npm run addon -- --live` (add `--region=eu,us` for both regions).
   Plain `npm run addon` builds from `./out` instead, but a local `npm run prices` has no sales history, so "sold per day" stays empty.
2. Copy `addon/ForeverAnvil` and `addon/ForeverAnvil_Data_EU` into the game's `Interface/AddOns` folder.
3. In game: `/fa` should name your ruleset and house. If it asks, set it with `/fa ruleset PvP` (or Normal, Roleplay, RP-PvP).

## The Forever client (confirmed in game, 2026-11-22)

- Interface `16001`, build 71037. It's built on the modern game engine with the old world's content, so it has the modern APIs and windows, not the classic ones.
- Tooltips use the modern tooltip system (`TooltipDataProcessor`). There's no global `GetItemInfo`, only `C_Item.GetItemInfo`; expect other classic globals to be missing too.
- The profession window is the modern one (`Blizzard_Professions`): profits come from `C_TradeSkillUI.GetRecipeSchematic`, and rows from the recipe list's `ScrollBox`.
- The auction window is the modern one (`Blizzard_AuctionHouseUI`). Its browse rows get only an index, which the addon looks up in the list. The window's code can load before the list is set up, so the addon hooks windows when they open (`AUCTION_HOUSE_SHOW`, `TRADE_SKILL_SHOW`) and never asks the list for rows before it's ready.
- The classic windows are still supported, in case another client uses them. `/fa debug` shows which windows and hooks are in use.

## Not checked in game yet

- Guessing the ruleset from the realm name (so far it's been set by hand with `/fa ruleset`).
- The neutral (Blackwater) house, used while you're at the auction house in Stranglethorn, Tanaris or Winterspring.
- Vendor-flip tags (none were on the market while testing; disenchant tags are confirmed).
